# GoBoult — 3D ANC Headphones Scroll Animation

An interactive, Apple-style 3D scroll-driven product experience built for **GoBoult** wireless over-ear ANC headphones.

Developed by **S John Paul**.

## Highlights

- **Photorealistic 3D Scroll Scrubbing**: 240 high-resolution (1080p) frames revealing an exploded teardown view of the headphone's drivers, acoustic chamber, lithium battery, and sound processor.
- **Cinematic Asymptotic Smoothing**: Sub-pixel linear interpolation (`lerp`) engine rendering at 60fps/120fps.
- **5 Synchronized Product Sections**:
  1. **Overview**: Brand narrative, wearable market leadership, and sales metrics (`4cr+` units sold, `00:03` sale velocity, `40L+` reviews).
  2. **Design**: Build & ergonomics (`Fold it, wear it, love it`), ANC badge, memory foam ear cushions, and rotational hinges.
  3. **Features**: Bento grid showcasing `40 mm` bass-boosted drivers, audio controls, ENC calling, `60ms` low-latency gaming mode, `BT v5.4`, `70 hrs` battery, and integrated sound processor.
  4. **Comparison**: Side-by-side spec showdown vs other brands (`Proudly Made in India`, consistent performance, premium materials).
  5. **Explore & Footer**: Newsletter subscription (`Step into the world of GoBoult`), categorized catalog links, and patent attribution.
- **Minimal Pure-Text Navbar**: Non-intrusive floating navigation (`Overview`, `Design`, `Features`, `Comparison`, `Explore`) with real-time active section tracking.
- **Zero Framework Bloat**: Pure HTML5 Canvas, modern CSS, and vanilla JavaScript.

## Getting Started

### Method 1: Double-Click (Windows)
Double-click `start.bat` to launch the local server and open `http://localhost:3000`.

### Method 2: Command Line
```bash
npm start
```
*or*
```bash
node server.js
```
Then visit `http://localhost:3000` in any modern web browser.
